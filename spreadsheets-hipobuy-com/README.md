# spreadsheets-hipobuy-com

Production source for `https://spreadsheets-hipobuy.com/`.

## Cloudflare Pages

- Root directory: `spreadsheets-hipobuy-com`
- Build command: `npm run build`
- Build output directory: `dist/client`
- Node.js version: `22`

The project exports static HTML for the homepage, product index, finds, articles,
buyer guide, QC, shipping and FAQ routes. `robots.txt` and `sitemap.xml` are
generated during the build.
