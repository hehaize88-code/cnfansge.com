# 多语言方案

状态（2026-10-20）：原有 24 语言界面已上线；本轮为 FAQ 和 10 篇文章补齐完整静态翻译。构建前检查每种语言的段落、清单、来源和机器字段完整性；不允许英文正文回退。实际发布结果见 PROJECT_MEMORY.md 最新记录。

## 网址

英文首页使用 https://pikobuy.at/，英文商品目录使用 /spreadsheet/；其他语言使用语言前缀，如 /de/spreadsheet/、/fr/spreadsheet/。德语入口在选择器中前置，英文仍作为根路径默认语言。不按 IP 强制跳转。

各语言通过同一个模板读取相同的 cnfansge 商品、原商品 ID、分类、排序、价格和图片。语言切换不减少商品量、不换到另一个商品库。

## 翻译范围与数据共享

- 导航、筛选、按钮、错误、空结果、分页、图片说明、SEO 标题、描述、正文均使用完整翻译词典或内容文件。
- 翻译词典是界面与内容资源，不是第二个商品数据库；不复制每种语言的商品清单。
- 商品名、规格以源站为准；源站若已有可靠多语字段优先使用。源站没有翻译的字段保留原文并标明，不改商品 ID、不改规格含义、不生成虚假卖点。所有语言中的源数据数量和字段应一致。
- 所有价格仍显示 USD，使用语言习惯格式化小数和分隔符；切换语言不改变商品价或汇率。
- 不通过每次访问调用翻译服务来改写整页，避免标题闪烁、内容缺失及不稳定索引。

## 切换行为

切换只替换语言前缀。保留商品或文章路径，并保留 search、category、sort、direction、page 等实际使用的参数。上述参数名为站内设计，源站参数由适配层映射。

搜图查询只在源站允许复用且结果标识不含敏感凭据时保留结果。否则在页面内解释重新查询，不把上传内容放到 URL，也不默认上传到翻译服务或第三方。

本地存储只可记住语言偏好；不创建浏览器商品数据库。直接访问一个明确语言 URL 时，以 URL 为准。

## SEO 与发布条件

HTML lang 与页面一致；每个有完整正文的语言页自引用 canonical；对应语言页使用互相一致的 hreflang；x-default 指向英文对应页。24 种语言的映射必须基于实际发布集合生成。

不将所有语言 canonical 指向英文首页，不让语言按钮打开 404，不发布英文正文套外语标题的占位页面。搜索结果、任意过滤组合与暂存搜图结果原则上不作为大量索引入口。

缺翻译时构建应提示并阻止该语言发布。首页、独立页与文章同时核对，而不只核对导航文字。核心验收包括对应路径存在、内容段落完整、商品 ID 一致、参数保留、双向 hreflang、语言切换文字对比度及手机端菜单可用。
