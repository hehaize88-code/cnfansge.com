# 数据接入约定

核验日期：2026-10-20。状态：浏览器公开页面验证；尚无程序化 API 接入实现。

## 数据边界

cnfansge.com 是唯一商品来源。子站只负责呈现、语言界面、SEO 内容以及 Pikobuy 购买链接，不创建商品数据库、不编造商品、不复制其他推荐站商品或图片。允许短期公开 HTTP 响应缓存，不持久化另一套商品目录，不引入 D1、SQL、KV 商品集合或提交 products.json。

后台与管理登录不在任务范围。数据为空、请求失败、接口不可用必须有不同状态，禁止用演示商品填补。

## 价格陷阱

样本详情原始页面数字为 169，页面脚本加载后的显示为 $23.28。列表也观察到数字先出现再转换。JSON-LD 中的 USD 标注与页面运行后的数值不一致，因此不能盲信该标签。

必须复用主站实际币种及转换规则，或取得源站可验证的最终美元价格；不把 169 写为 USD 169，不根据两个样本自行假定固定汇率。主站运行后的价格用于交叉核对，不作为子站硬编码商品价格。

## 最小商品映射

`sourceRecordId` 用于来源记录定位；`marketplace` 与 `marketplaceProductId` 用于购买链接；图片须保留主图、普通图库、已确认 QC 的区别。其他必要字段包括源 URL、标题、原币种与金额、已验证美元金额、更新时间、分类和可选规格。

字段缺失保留空值。不要猜商品原平台、价格、库存、QC 数量或规格。

## 接入实现顺序

1. 验证程序能够读取源站已有公开接口；若源站只有 HTML，评估按请求解析公开页面，仍不落库。
2. 记录实际请求、分页、排序、价格和图库语义，避免写入未经证实的 API 地址。
3. 将每个动态请求限定至已验证的源站域名及路径，校验查询参数；拒绝任意 URL 代理。
4. 控制超时、并发与重试；429 尊重 Retry-After，不重复高频请求。
5. 搜图上传接口核实后再开放上传按钮；不把上传按钮做成无效装饰。
6. 根据源站字段确认 QC 展示，而非将整个卖家图库重新标为 QC。

这些验证在公开前台完成，不要求后台账号，也不操作主站后台。
