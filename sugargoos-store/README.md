# sugargoos.store

Independent, category-first Sugargoo finds and warehouse inspection decision library.

- Production: `https://sugargoos.store/`
- Canonical host: apex HTTPS
- Languages: English at `/`, plus `/de/`, `/es/`, `/fr/`, `/it/`
- External CTA target: `https://cnfansge.com/`
- Worker: `sugargoos-store`

The site deliberately avoids the broad beginner/platform-workflow positioning used by `sugargoos.shop` and the Germany/VAT/customs positioning used by `sugargoos.de`.

Run `npm test` before deployment. The Worker has no runtime dependencies.
